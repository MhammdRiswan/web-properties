# Product: Website Properties Perumahan

A frontend-only platform for browsing residential property listings in Indonesia. Users can search, filter, sort, and save favorite properties, then view full details including photo galleries, maps, and a contact form to reach agents.

## Core Features

- Property listing with infinite scroll and entrance animations
- Search by keyword (location, name, description) with 500ms debounce
- Multi-criteria filtering: price range, bedrooms, bathrooms, land area, property type
- Sorting: newest, lowest price, highest price, largest area
- Property detail page: full info, image gallery with lightbox, interactive map, share buttons
- Favorites/wishlist persisted in localStorage
- Responsive design: mobile-first, hamburger menu, filter drawer on mobile
- Accessibility: WCAG AA compliant, keyboard navigable, screen reader friendly

## Target Users

Indonesian property seekers browsing on both mobile and desktop devices.

## Language

UI text and content is in **Bahasa Indonesia**. Code, comments, and technical documentation may be in English.
